# Task Management App
A simple to-do list web app built with Flask.

## Features
- Add tasks
- Edit tasks
- Mark tasks as done
- Quick-add via natural-language prompt

## Tech Stack
- Python 3.11
- Flask
- Jinja2
- SQLite


## Installation

1. Clone the repo
   git clone https://github.com/you/project.git

2. Create a virtual environment
   python -m venv venv

3. Activate it
   .\venv\Scripts\activate  (Windows)
   source venv/bin/activate (Linux/Mac)

4. Install packages
   pip install -r requirements.txt

5. Run
   python app.py
